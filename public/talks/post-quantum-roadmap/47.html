Where to start

Summary: PQC migration planning roadmap

  1. Phase 1

    Assess & inventory

    Now – Q4 2026

    • Catalog all cryptographic usage: asymmetric keys, certificates, cipher suites, HSMs
    • Identify obsolete algorithms (MD5, DES, SHA-1) and remediate immediately
    • Protect key exchanges – stop transmitting long-lived keys over public networks

  2. Phase 2

    Prepare infrastructure

    2026 – 2027

    • Upgrade OS: Linux OpenSSL 3.5+, Windows Server 2025+, macOS Tahoe 26
    • Update HSMs and network hardware, and modularize custom cryptographic code
    • Budget for certificate renewals, server upgrades and code refactoring

  3. Phase 3

    Enable hybrid PQC

    2027 – 2029

    • Deploy hybrid PQC/classical certificates and cipher suites (ML-KEM, ML-DSA)
    • Update JWT, OAuth, SAML, VPN and MLE to support PQC signatures
    • Re-encrypt historical data: backups, audit logs, retained messages

  4. Phase 4

    PQC-only transition

    2029 – 2030+

    • Mandate PQC-only cipher suites and retire classical asymmetric algorithms
    • Validate quantum resistance as real quantum threats emerge (mid-2030s)
    • Maintain agility – design for future algorithm replacement, not if but when
